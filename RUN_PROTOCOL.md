# Run protocol (do this identically for ChatGPT and DeepSeek)

Before each run
1. Open a NEW chat for every run (6 chats total: ChatGPT x3, DeepSeek x3). Never continue an old chat.
2. Settings: web search OFF, memory / custom instructions OFF (or use a temporary/incognito chat), DeepSeek "DeepThink" = same setting every run (write it down). Don't change the model between runs.
3. Attach commons-cli-scope.txt, then paste prompt.txt exactly as is. Do not edit or add anything.
4. Copy the full answer into runs/<model>_run<N>.txt, and take a screenshot that shows the model name/version label, the prompt, and the answer (scroll for several screenshots if long).
5. Write down: date and time, model label shown in the UI, interface (web), settings.

Do not re-roll / regenerate; one answer per chat = one run.
